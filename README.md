# Georgetown HSOC — Workbench Examples

## Overview

Curated examples for Georgetown HSOC showing how to work with data and cloud resources in [Verily Workbench](https://workbench.verily.com). Each subfolder contains a self-contained example with its own README and runnable scripts.

## Getting Started

### 1. Create an App

In the [Workbench web UI](https://workbench.verily.com), navigate to your workspace and [create a new JupyterLab or R Analysis Envrionment app](https://support.workbench.verily.com/docs/guides/cloud_apps/app_operations/#create-a-new-cloud-app).

### 2. Clone This Repository

Open a terminal and run:

```bash
cd ~/repos
git clone https://github.com/verily-src/workbench-examples.git
cd workbench-examples
git checkout georgetown-hsoc
```

### 3. Navigate to the Examples

```bash
cd georgetown-hsoc
```

You're ready to explore the example folders listed below.
